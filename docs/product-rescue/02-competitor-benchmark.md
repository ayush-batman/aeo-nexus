# Competitor Benchmark

## Method and limits

Public pages and documentation were reviewed on 2026-08-29 for Profound, Peec AI, Otterly, Mentions, Listable Labs, Scrunch AI, and AthenaHQ. This is a product-pattern comparison, not a claim about private implementation. Authenticated experiences and statistical sampling methods were not verified. Long-tail competitors in `COMPETITORS.md` remain roster context only unless linked below.

## Meaningful patterns

### Profound

**Observed:** [pricing](https://www.tryprofound.com/pricing) emphasizes recommended prompts, daily tracking, answer volume, multiple engines, agents, integrations, and exports.  
**Problem solved:** operational scale for teams, not a decorative score.  
**Application to Aelo:** charge for cadence, prompts, teams, export, and evidence history after a trustworthy free result. Avoid copying enterprise breadth before measurement integrity.

### Peec AI

**Observed:** [quickstart](https://docs.peec.ai/quickstart-guide) and [performance documentation](https://docs.peec.ai/understanding-your-performance) connect Visibility, Brands, Top Sources, Recent Chats, source types, source gaps, and prompt drill-down.  
**Problem solved:** turns “where do I rank?” into “which sources should I influence?”  
**Application to Aelo:** make Sources the bridge from measurement to one ranked action; keep each source tied to exact prompt/engine/sample evidence.

### Otterly

**Observed:** [prompt monitoring](https://help.otterly.ai/search-prompt-monitoring) and [pricing](https://otterly.ai/pricing/) emphasize a customizable prompt table, response-level/engine drill-down, daily tracking, citations, and exports/API/MCP at higher tiers.  
**Problem solved:** understandable SMB operations at a low entry price.  
**Application to Aelo:** a strong Prompts & Scans table is table stakes. Differentiate on confidence, provenance, and comparable intervention proof—not more menu items.

### Mentions

**Observed:** [public site](https://mentions.so/) foregrounds a recommendation Kanban and pricing from $49; public crawler area contained placeholder content during review.  
**Problem solved:** creates a visible work queue from findings.  
**Application to Aelo:** one persistent Actions board is relevant. Avoid marketing any placeholder analytics or weakly connected modules.

### Listable Labs

**Observed:** [pricing](https://www.listablelabs.com/pricing) showed $60/$150/$400 public tiers, daily tracking, three included models, high answer volumes, content/social generation, MCP, geography, integrations, and white-label features.  
**Problem solved:** broad India-focused alternative for agencies and teams.  
**Application to Aelo:** India origin alone is not a moat. ₹ checkout, Indian query calibration, credible local benchmarks, and statistically honest evidence can be.

### Scrunch AI

**Observed:** [public site](https://origin.scrunchai.com/) uses a fast URL audit and an observe → understand/act → deliver narrative.  
**Problem solved:** very low-friction first value and a clear journey.  
**Application to Aelo:** preserve the free scan, then visibly graduate the user to the multi-sample decision packet.

### AthenaHQ

**Observed:** [public site](https://athenahq.ai/) claims broad model coverage, copilot, source/competitor insight, actions, and a higher entry price.  
**Problem solved:** breadth for mature teams.  
**Application to Aelo:** evidence that breadth can command price, not evidence Aelo should build breadth before core trust.

## Classification

### Table stakes Aelo is missing or under-delivering

- A clear prompt-centric operating surface.
- Source taxonomy and source-gap workflow tied to evidence.
- Persisted collaborative action queue.
- Straight path from onboarding to a trustworthy first result.
- Daily/weekly operational state with change explanation.
- Reliable loading, empty, error, partial, and provider-outage states.
- Exports/reporting that preserve sample and provenance metadata.

### Areas already competitive

- Multi-sample API response with sample count/agreement confidence.
- API-key-scoped `/api/v1` and MCP product surface.
- No-signup public scan and shareable receipt.
- Intervention concept and explicit “prove” step.
- India/₹/Razorpay positioning.

These are architectural/product assets, not yet proof of a production-quality experience.

### Differentiation opportunities

1. **Measurement honesty:** show samples, agreement, engine/model/version, failures, and raw evidence.
2. **Source provenance:** distinguish provider-grounded citations from links merely mentioned in generated text.
3. **Comparable intervention proof:** pre-registered baseline/follow-up measurement cohorts rather than single-point causality.
4. **India calibration:** Indian query variants, sources, language/region, and public index methodology with reproducible receipts.
5. **Decision packet:** one weekly result that connects change → source gap → action → proof.

### Features to intentionally avoid now

- Generic AI content studio expansion.
- Autonomous posting or bought-mention mechanics.
- Crawler analytics without real data integrity.
- More engines before current engine liveness/provenance is observable.
- Agency white-label breadth before safe tenancy and collaboration.
- Feature parity with enterprise agents/copilots.

### Superficial differences with little customer value

- Different card colors, gradients, animations, or dashboard chrome.
- More blended scores without uncertainty.
- More menu destinations.
- Claiming category leadership or “all systems operational” without evidence.
- Naming model versions as a marketing feature when liveness is not monitored.

## Strategic conclusion

Aelo should not compete on feature count. The winning position is: **the visibility instrument whose numbers can survive a skeptical review.** The roadmap should make statistical repeatability, source provenance, and comparable intervention evidence obvious in the default journey.
